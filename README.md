# Matemáticas · Guías interactivas UNaM

Guías de práctica de Matemática para **Bioquímica (FCEQyN – UNaM)** convertidas en una página web interactiva.

Cada ejercicio tiene visualizaciones que se mueven, comprobadores de respuestas y la resolución paso a paso explicando qué propiedad se usa en cada paso.

## Contenido

| Guía | Tema |
|------|------|
| G1 | Números reales: potencias, radicales, ecuaciones, inecuaciones, valor absoluto, logaritmos |
| G2 | Vectores en el plano y en el espacio |
| G3 | Rectas, planos y cónicas |
| G4 | Funciones |
| G5 | Límite y continuidad |
| G6 | Derivadas |
| EX | Ejercicios de parciales y recuperatorios anteriores |

## Características

- **Comprobador de respuestas**: acepta fracciones, coma decimal y raíces (por ejemplo `3+3√2`).
- **Resolución paso a paso** de cada ejercicio.
- **Gráficos interactivos** para explorar cada concepto.
- **Botón Propiedades**: todas las fórmulas de cada guía en un solo lugar.
- **Progreso guardado** en el navegador.
- Funciona en celular y en computadora.
